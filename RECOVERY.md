# Восстановление MyBudget из APK

**Источник:** `app-debug.apk` (versionCode 16, package `ru.mybudget.app`)  
**Дата декомпиляции:** 2026-08-18  
**Инструмент:** JADX 1.5.1

## Что уже сделано

| Папка | Содержимое |
|-------|------------|
| `decompiled/sources/` | Java-код (JADX), включая `ru.mybudget.app.*` |
| `decompiled/resources/` | `res/`, `AndroidManifest.xml`, assets |
| `tools/jadx/` | JADX для повторной декомпиляции |
| `app/` | Gradle-модуль: ресурсы приложения, манифест, Kotlin-каркас |
| `app/build/outputs/apk/debug/app-debug.apk` | Первая сборка `assembleDebug` (этап 1) |

Декомпиляция завершилась с **22 некритичными ошибками** JADX — это нормально для больших APK.

## Как открыть в Cursor

1. **File → Open Folder** → `M:\MyBudget`
2. Сборка: `gradlew.bat assembleDebug`

## Ограничения

- Kotlin-исходники **не восстанавливаются байт-в-байт** — JADX даёт Java без `@Entity`/`@Query`. Пишем Kotlin по декомпиляции.
- Gradle, тесты, `docs/` — **пересобираем вручную**.
- **Данные пользователя** — из JSON-бэкапа приложения, не из APK (`MyBudget_backup_2026-08-18.json`).

## Полезные команды

```bat
REM Повторная декомпиляция
M:\MyBudget\tools\jadx\bin\jadx.bat -d M:\MyBudget\decompiled --show-bad-code M:\MyBudget\app-debug.apk

REM Перенос только app-ресурсов из JADX
powershell -ExecutionPolicy Bypass -File M:\MyBudget\tools\restore_app_resources.ps1

REM Сборка
gradlew.bat assembleDebug
```
