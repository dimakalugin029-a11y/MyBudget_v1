# Экран события Авто

Добавление и редактирование ТО, ремонта, бензина и ОСАГО открывает
AutoEntryActivity вместо прежнего AlertDialog. В Intent передаются тип,
идентификатор записи и автомобиль; существующая запись загружается из базы.
Список Авто обновляется через прежний onResume после возврата.

Форма использует общую тему, подписанные поля и карточки. Основные сведения,
сумма, работы/запчасти и оплата разделены. Итог и сохранение закреплены вне
прокрутки, включён adjustResize для клавиатуры. Дата выбирается календарём.
Для каждой позиции есть удаление. Поля и динамические позиции сохраняются
при пересоздании формы после завершения её загрузки.

Сумма ТО/ремонта с заполненными позициями вычисляется по позициям и не
редактируется отдельно. Без позиций доступен ручной итог, в том числе для
старых записей с общей суммой. Бензин рассчитывается из литров и цены с
сохранением точности исходных полей; для ОСАГО вводится общая стоимость.
Комментарий показывается для ТО/ремонта: отдельные комментарии бензина и
ОСАГО текущие сущности не хранят. Поля, которые не сохраняются, не предлагаются.
Формат описаний с позициями сохранён для совместимости со старыми событиями.

Валидация даты, пробега, суммы, позиций и оплаты перенесена из прежнего
редактора. Запись по-прежнему выполняется AutoRepository.saveEntry одной
транзакцией вместе с оплатой. Подтверждение перерасхода, учёт старого
списания при редактировании, наличная/бюджетная оплата и отсутствие оплаты
сохранены. Схема базы данных не меняется.

## Проверка на телефоне

- Открыть старый ремонт с несколькими позициями: все названия, цены,
  комментарий, дата, пробег и способ оплаты восстановлены.
- Изменить цену, добавить и удалить позицию: итог соответствует списку.
  Пустая позиция не сохраняется; неполная позиция требует исправления.
- Старое ТО без позиций: ручная сумма остаётся доступной. Добавить позицию,
  проверить переход на рассчитанный итог, затем удалить её.
- Бензин: дробные литры и цена, итог после округления до копеек, пробег.
  ОСАГО: даты начала/окончания, ручная стоимость, недопустимый порядок дат.
- Наличные, без оплаты, бюджет; изменить сумму и статью ранее оплаченного
  события. В бюджете изменяется существующее списание, лишний расход
  не появляется. Проверить согласие и отмену подтверждения перерасхода.
- Повернуть экран с несколькими введёнными позициями, поменянными полями
  и способом оплаты. Проверить обе темы, увеличенный шрифт, клавиатуру
  и доступность кнопки сохранения при прокрутке.

APK и эмулятор не запускаются. Компиляция и модульные тесты не заменяют
визуальную проверку экрана и сценариев оплаты на устройстве.
