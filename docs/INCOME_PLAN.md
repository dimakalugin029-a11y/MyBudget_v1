# План дохода

## Расчёт

План относится к выбранному бюджету и месяцу. Зарплата, аванс и прочие источники — ежемесячные. Для премии доступны месячные, квартальные и годовые выплаты. Первый месяц квартальной выплаты определяет последовательность через каждые три месяца; годовая выплата полностью учитывается в указанном месяце. Одинаковая формула используется на главном экране, в плане дохода, календаре и бюджетировании. Месячная поправка из бюджетирования имеет приоритет, отключённый месяц даёт ноль. Прогноз использует те же базовые месяцы выплат.

«В среднем за месяц» — отдельная справка по базовому расписанию: квартальная сумма / 3, годовая / 12. «После обязательств по плану» вычитает среднюю месячную нагрузку обязательств из среднего базового дохода. Это не остаток денег на счетах и не разрешённый расход: повседневные расходы здесь не учитываются.

## Получение

Кнопка в карточке источника открывает запись получения за выбранный месяц. Можно записать часть суммы или распределить её по статьям. Подсказки в обычной форме дохода также связывают поступление с источником и месяцем; при необходимости связь можно снять. Доход без фиксированной даты доступен для получения из карточки, но не создаёт событие календаря.

Получено — сумма реальных операций income с plannedIncomeSourceId и plannedIncomeMonth. Остаток считается отдельно для каждого источника и не опускается ниже нуля. Полностью полученная выплата исчезает из ожидаемых событий календаря. Неполученные даты в прошлом не переносятся автоматически на сегодня; остаток доступен в плане соответствующего месяца.

Сервис IncomePlanExecution атомарно проверяет актуальный остаток, записывает операции и обновляет балансы. Повтор того же запроса с groupId не зачисляет деньги снова. Сумма выше остатка требует изменения плана либо записи отдельного обычного дохода. Для распределения сохраняется связь также в незавершённом остатке.

Исправление суммы и отмена операций пересчитывают полученное автоматически. При изменении типа на расход либо переносе операции в другой бюджет связь снимается. Перераспределение связанной группы заменяет старую группу только при успешном сохранении новой в одной транзакции.

## Совместимость

База 44 добавляет два nullable поля к операциям, старые записи остаются без связи. Автоматического сопоставления по названию/сумме нет. Резервные копии версии 23 сохраняют поля операций; при восстановлении и объединении идентификаторы источников переназначаются. Отсутствующая или некорректная связь сбрасывается, сама денежная операция сохраняется.

## Проверка в Android Studio

Сборка и запуск тестов по договорённости остаются за пользователем. Добавлены исходники проверок: месяцы премий, месячные поправки, частичные поступления, повторные и параллельные запросы, отмена, редактирование, атомарное перераспределение, миграция и переназначение связей при импорте. На устройстве проверить также смену месяца/бюджета, получение через календарь и сохранение остатка распределения.
