# Компактный экран плана дохода

- Заголовок и переключение месяца остаются на экране.
- Сводка, подсказка и переход к обязательным платежам прокручиваются вместе со списком через AppBarLayout. При прокрутке вверх сводка возвращается.
- Сводка показывает план, получено, ещё ожидается; непривязанные поступления вынесены отдельной короткой строкой.
- Кнопка «Подробнее о плане» открывает прокручиваемое стандартное окно с прежними расчётами среднего дохода, обязательств и пояснениями. Обычный информационный текст больше не выделяется красным на зелёном фоне.
- В карточках уменьшены отступы, сумма плана для выбранного месяца показывается один раз. Состояние поступления, отклонение, обязательства и действия сохранены.
- Расчёты и данные не изменялись.

Проверить на устройстве: длинный список и один источник, сворачивание и возврат сводки, переключение месяца при свёрнутой сводке, большое системное увеличение шрифта, обе темы, подробности при наличии непривязанных поступлений, получение дохода и редактирование источника.
