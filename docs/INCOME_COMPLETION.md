# Окончательное и частичное поступление

В форме дохода, связанном распределении и привязке старого поступления
пользователь выбирает окончательное или частичное получение. По умолчанию
выбрано окончательное. Для дохода вне плана выбор скрыт.

План не заменяется фактом. Получено — сумма фактических связанных операций.
Отклонение равно факту минус план. Если есть окончательное поступление,
ожидание равно нулю независимо от отклонения; иначе оно равно положительной
разнице плана и факта. Закрытие относится только к выбранному источнику
и месяцу, будущие месяцы сохраняют свой прогноз.

В плане доступны «Завершить получение» и «Снова ожидать поступление».
Эти действия не начисляют деньги и не меняют исходную плановую сумму.
Нельзя завершить получение без фактических связанных операций.

База 50 добавляет incomePlanFinal к транзакциям (DEFAULT 0). Старые данные
остаются частичными/незакрытыми. Признак хранится на строках последней
окончательной группы. Новая окончательная группа снимает прежние маркеры
источника за месяц. Удаление любой строки группы снимает маркеры всей этой
группы, поэтому ожидание открывается снова. Исправление суммы в том же
бюджете сохраняет статус, смена типа операции/бюджета снимает его.

Прогноз читает связанные поступления отдельно от экономической истории:
закрытые разницы не становятся будущими деньгами и не меняют исторические
средние. Частично полученные суммы уменьшают ожидание. Бюджетные остатки
не получают фактический доход повторно.

При неполном распределении окончательный статус фиксируется только после
распределения всей введённой суммы; остаток и выбор сохраняются в черновике.
Поворот формы сохраняет выбор. Резервные данные версии 28 сохраняют признак;
при неверной/утерянной связи импортер очищает его. Старые копии не получают
окончательный статус автоматически.

Проверить на телефоне: план 14500, факт 14100 окончательный → получено14100,
отклонение−400, ожидание0, текущий прогноз без400. Частичный → ожидание400.
Повторить распределением в несколько статей, продолжением остатка,
привязкой уже полученного дохода, закрытием/возобновлением из плана,
правкой суммы, отменой одной строки и группы, восстановлением копии.
