# Топливо и страховки

Топливо: необязательные текстовые поля тип топлива и АЗС; можно вписать
своё значение. Страховка: ОСАГО или КАСКО, необязательные компания,
номер полиса и телефон. Каждый полис — отдельная запись с независимыми
датами, оплатой и напоминанием. Одновременные ОСАГО и КАСКО не заменяют
друг друга. Телефон и номер полиса можно прочитать и скопировать в карточке.

Поля передаются через форму, черновик при повороте, AutoEntry, Room,
экспорт и импорт. Просмотр показывает заполненные реквизиты, пустые
строки не выводятся. Оплата и статистические суммы не пересчитываются
при изменении реквизитов. Напоминания указывают тип полиса.

База 49 добавляет два текстовых поля топлива и четыре поля страховки.
Старые строки получают пустые реквизиты и тип osago. Историческая схема 48
сохранена с хешем. Резервные данные версии 27 включают новые поля;
старый JSON нормализуется перед импортом, отсутствующие строки не
передаются как null в обязательные столбцы Room.

На телефоне проверить создание и правку дизеля/бензина с названием АЗС,
поворот формы с заполненными реквизитами, два одновременных полиса,
смену способа оплаты без потери полей, чтение длинного номера полиса,
экспорт и восстановление новой и старой копии. Новые поля необязательны.
