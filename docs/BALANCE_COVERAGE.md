# Покрытие перерасхода переводами

Из предупреждения «Проверьте лимиты статей» открывается отдельный экран.
Выбирается одна статья с отрицательным остатком; можно использовать несколько
положительных статей этого же активного бюджета и погасить долг частично.
Для нескольких долгов операция повторяется с выбором следующей статьи.
Родители с активными подстатьями не используются как отдельные источники:
это исключает повторный учёт агрегированной суммы.

Пользователь задаёт суммы, затем видит подтверждение с остатком каждого
источника и получателя. Никакого автоматического списания нет. Положительный
остаток может быть нужен для будущих платежей, поэтому выбор источников
остаётся за пользователем.

Лимит расходов и минус остатка — разные показатели. Перевод не меняет
исторический расход и не снимает превышение лимита. Если отрицательных
остатков нет, экран объясняет это и позволяет перейти в Бюджет.

Команда проверяет активность профиля, принадлежность и активность статей,
конечные положительные суммы, достаточность каждого источника, отсутствие
переплаты сверх минуса, совпадение остатков с подтверждённым расчётом.
Room-транзакция объединяет все переводы и квитанцию requestId. Повтор того
же запроса не переводит деньги повторно. Доходы/расходы не создаются;
движения записываются в журнал с типом transfer и одним operationId.

ViewModel переживает поворот и блокирует повторное сохранение. Черновые
суммы и выбранная статья сохраняются при пересоздании экрана. Ошибки
обновления виджета после фиксации не выдаются за неуспешный перевод.

Проверить на телефоне: несколько источников, частичное погашение,
нехватку средств, ввод суммы выше минуса, поворот во время подтверждения
и сохранения. До и после сравнить общий остаток, историю доходов/расходов
и остатки выбранных статей. При изменившихся остатках открыть экран заново.

Идентификатор команды хранится в SavedStateHandle: восстановление процесса
не создаёт новый идентификатор для того же черновика. Изменений схемы БД нет.

Проверки: 272 модульных теста без ошибок/падений/пропусков.
Android-тесты скомпилированы, включая BalanceCoverageIntegrityTest;
на устройстве они не выполнялись. XML и git diff --check прошли.
APK не собирался.

## Список источников

Источники сгруппированы по родительской статье. Каждая подстатья находится
в отдельной карточке с названием, подписанным текущим остатком, полем суммы
и предварительным остатком после перевода. Самостоятельные статьи вынесены
в свою группу. Подписи не называют остаток свободными деньгами. Черновики
по-прежнему восстанавливаются по ID статьи, независимо от группировки.
Изменение касается отображения; правила подтверждения и переводов прежние.
